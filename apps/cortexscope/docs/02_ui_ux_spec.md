## 5 Interactive Views
**CortexScope HUD Views:**

1.  **Live Pulse Proxy:** Real-time server ping radar using `tabular-nums`. Click a node to auto-route traffic; toggle "Failover" instantly.
2.  **Token Latency Heatmap:** Hex grid visualizing latency spikes (cyan=low, amber=high). Hover for microsecond breakdown; click to trigger auto-throttle.
3.  **A/B Model Arena:** Split-screen comparison of two model outputs with side-by-side token cost metrics. Drag sliders to adjust temperature/penalty dynamically.
4.  **Modelfile/Context Workbench:** Syntax-highlighted editor for YAML configs. Real-time preview pane shows context window impact on inference speed.
5.  **History Quantile Explorer:** Interactive histogram of historical latency
